# 🤖 Hermes Agent — 24/7 Discord Assistant

An autonomous, ultra-fast Discord AI assistant powered by **Google Gemini 2.5 Flash** with multi-platform research capabilities via **Agent Reach**.

## ✨ Features
- **⚡ Fast Responses:** Sub-second replies powered by Gemini 2.5 Flash.
- **📡 Agent Reach Research:** Live multi-platform lookups (Reddit, LinkedIn, YouTube, GitHub, web search).
- **🧠 Persistent Memory:** Remembers conversations across channels and sessions.
- **🎯 No-Fluff Personality:** Strict concise formatting optimized for mobile and Discord chats.

## ⚙️ Environment Variables
| Variable | Description |
| :--- | :--- |
| `GEMINI_API_KEY` | Google Gemini AI Studio API Key |
| `DISCORD_BOT_TOKEN` | Discord Developer Bot Token |
| `DISCORD_ALLOWED_USERS` | Allowed Discord User IDs (`*` for all users) |
