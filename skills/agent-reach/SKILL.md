# Agent Reach — Fast Web & Social Research

When asked to search the web, fetch live news, read URLs, or find community discussions:

## Quick Commands:
1. **Read any web page / article:**
   `curl -s "https://r.jina.ai/URL"`
2. **YouTube Video Transcription:**
   `yt-dlp --write-sub --write-auto-sub --skip-download -o "/tmp/%(id)s" "URL"`
3. **GitHub Search:**
   `curl -s "https://api.github.com/search/repositories?q=QUERY&per_page=5"`

Always summarize findings directly in 2–4 concise bullet points.
